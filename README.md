# GUI Calculator

Калькулятор на Tkinter. Проверены обработчики кнопок, деление на ноль, знак нуля и повторное использование результата в экспоненциальной записи. Сетевых запросов и внешних сервисов нет.

Требуется Python с Tkinter для GUI-проектов.

```bash
python main.py
```

Проверка:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
```

GUI-тесты создают настоящие виджеты в скрытых окнах.
